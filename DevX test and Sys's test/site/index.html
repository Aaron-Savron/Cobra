Mock API endpoints

GET /api/ping Latency probe. Returns server-side handling time in microseconds.
GET /api/fib?n=28 Recursive Fibonacci — a pure CPU benchmark.
GET /api/stress?n=500000 500k-iteration sum-of-squares loop.
GET /api/json?n=100 Serializes a 100-record JSON array by hand into a byte buffer.
POST /api/echo Echoes body metadata back as JSON.
